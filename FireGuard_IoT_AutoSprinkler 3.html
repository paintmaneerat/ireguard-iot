เกี่ยวกับ FireGuard

FireGuard เป็นแบบจำลองการจัดการเหตุอัคคีภัยสำหรับรายวิชาเทคโนโลยีสมัยใหม่ในงานวิศวกรรม สร้างด้วย HTML, CSS, JavaScript และ SVG ภายในไฟล์เดียว เปิดแบบออฟไลน์ได้

ส่วนประกอบระบบ IoT

เซนเซอร์อุณหภูมิ ควัน และจำนวนคนใน 8 ห้อง ส่งค่าสถานะจำลองมายังศูนย์ควบคุม ข้อมูลเซนเซอร์ออนไลน์ใช้กระตุ้นการแจ้งเตือน และจำลองการไหลของควันไปยังทางเดิน หัวสปริงเกลอร์จำลองตรวจจับความร้อนโดยอิสระจากสถานะเซนเซอร์ IoT และเริ่มจ่ายน้ำในห้องที่ถึงเกณฑ์จำลอง

ระบบเลือกเส้นทาง

ใช้อัลกอริทึม Dijkstra หาเส้นทางจากห้องไปยังทางออก A หรือ B ต้นทุนเส้นทางรวมระยะทาง ปริมาณควัน ความร้อน และความหนาแน่นคน โหนดที่อันตรายเกินเกณฑ์หรือทางออกปิดจะไม่ถูกเลือก

วิธีทดลอง

เลือกห้อง → จุดไฟ → รอหัวสปริงเกลอร์จำลองตรวจจับความร้อนถึง 68°C และเริ่มฉีดน้ำเอง → สังเกตระดับไฟและควันที่เปลี่ยนไป → กดเริ่มอพยพเพื่อดูการเปลี่ยนเส้นทาง ลองปิด Dynamic safe routing เพื่อเปรียบเทียบกลยุทธ์

ข้อจำกัด

เป็นแบบจำลองเชิงการศึกษา ไม่ได้ใช้โมเดลพลศาสตร์อัคคีภัย การไหลของอากาศ หรือเกณฑ์การอพยพของอาคารจริง ผลลัพธ์ไม่ใช่คำแนะนำความปลอดภัยที่ใช้ได้ในสถานการณ์จริง
